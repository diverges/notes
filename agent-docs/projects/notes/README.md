# Notes: Agent memory

Meta-project: this shared guidelines and knowledge repository itself.

## How to use this folder

- Read this README, then [CONTEXT.md](CONTEXT.md). Load other files only when the "When" column applies.
- Overwrite CONTEXT.md each session (≤ 40 lines); add consequential guideline choices to decisions.md; never append to history.md.

| File | Holds | When |
| --- | --- | --- |
| [CONTEXT.md](CONTEXT.md) | Identity, current state, open items, next steps | Always |
| [decisions.md](decisions.md) | Dated guideline decisions, newest first | Changing guidelines, templates or repo structure |
| [learnings.md](learnings.md) | Agent lessons: query routing, absolute shared root, Windows symlinks | Setting up machines or organising knowledge |
| [history.md](history.md) | Archived dated diary (old CONTEXT.md, to 2026-10-03) | Never by default; search for a past event |
